Why specforge?

Most OpenAPI generators leave you building runtime infrastructure by hand. specforge generates complete, production-ready client libraries.

Full Composition

Complete allOf property merging, oneOf type guards, discriminator mapping, and nullable propagation. No more any-typed output.

Production Runtime

Auth providers, exponential backoff, pagination helpers, concurrency control, middleware, idempotency keys, and SSE streaming built-in.

Multi-Language

One IR, four targets. TypeScript, Go, Rust, and WASM plugins share the same resolved spec for consistent behavior across languages.

Runtime Validation

Catch contract violations in dev and tests with automatic request/response body validation against your OpenAPI spec.

Built for CI

specforge diff detects breaking changes, specforge check lints specs, and the GitHub Action gives you one-line CI integration.

Docs Generation

specforge docs generates a static HTML API documentation site from your spec. No separate tools needed.

WASM Plugins

Need Kotlin, Swift, or Python? Build a custom emitter as a WASM plugin with the specforge plugin SDK.

Mock Server Tests

specforge test generates mock server tests from example responses. Stop writing mocks by hand.

Multi-Language SDK Generation

Generate production-ready clients for TypeScript, Go, and Rust from the same OpenAPI spec. One source of truth, consistent behavior.

app.ts 
import { createClient, bearerAuth, streamSse } from "./sdk/src/index.ts";

const client = createClient({
  baseUrl: "https://api.example.com",
  auth: bearerAuth(() => process.env.API_TOKEN!),
  maxConcurrent: 8,
  dedupe: true,
  idempotency: true,
  retry: { maxRetries: 3 },
});

// Typed request & response — no `any`
const page = await client.pets.listPets({ limit: 20 });

// SSE streaming with proper error handling
const res = await client.request("GET", "/events");
for await (const ev of streamSse(res)) {
  console.log(ev.event, ev.data);
}
main.go 
package main

import (
    "context"
    "fmt"
    "log"
    "os"
    "time"

    sdk "github.com/acme/widget-go"
)

func main() {
    c := sdk.NewClient().
        WithBaseURL("https://api.example.com").
        WithBearerToken(os.Getenv("API_TOKEN")).
        WithTimeout(10 * time.Second).
        WithMaxConcurrent(8).
        WithDedupe(true).
        WithIdempotency(true).
        WithRetry(sdk.DefaultRetryOptions())

    // Middleware for logging & tracing
    c.Use(func(ctx context.Context, req *sdk.MiddlewareRequest,
        next func(context.Context, *sdk.MiddlewareRequest) (*sdk.MiddlewareResponse, error),
    ) (*sdk.MiddlewareResponse, error) {
        start := time.Now()
        res, err := next(ctx, req)
        log.Printf("%s %s %v", req.Method, req.URL, time.Since(start))
        return res, err
    })

    pets, err := c.ListPets(context.Background(), 20)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(pets)
}
main.rs 
use std::time::Duration;
use widget_sdk::{api, Client};
use widget_sdk::streaming::SseStream;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::builder()
        .base_url("https://api.example.com")
        .bearer_token(std::env::var("API_TOKEN")?)
        .timeout(Duration::from_secs(10))
        .max_concurrent(8)
        .dedupe(true)
        .idempotency(true)
        .build()?;

    // Fully typed request/response
    let pets = api::list_pets(&client, Some(20)).await?;

    // SSE streaming
    let res = client
        .request_stream(reqwest::Method::GET, "/events", &[], None)
        .await?;
    let mut sse = SseStream::new(res.bytes_stream());
    while let Some(ev) = sse.next_event().await? {
        println!("{}: {}", ev.event, ev.data);
    }

    Ok(())
}

CLI Reference

12 powerful commands to parse, validate, generate, and test your API SDKs from the command line.

Command Description
specforge generate Generate an SDK from an OpenAPI spec (TS, Go, or Rust)
specforge check Lint and validate an OpenAPI spec with configurable rules
specforge diff Compare two specs and report breaking changes (exit code 1 on break)
specforge emit Dump the resolved IR as JSON for external tools and plugins
specforge init Scaffold a new minimal OpenAPI spec with a /health endpoint
specforge convert Convert between OpenAPI 3.0 and 3.1 formats
specforge merge Merge multiple OpenAPI spec files into one
specforge docs Generate a static HTML API documentation site
specforge test Generate mock server tests from spec example responses
specforge versions List API versions in a spec directory
specforge workspace Generate SDKs for all specs in a workspace config
specforge workspace-init Generate a workspace config from a directory of specs
Example usage 
# Generate a TypeScript SDK
specforge generate openapi.yaml -o ./sdk-ts -l ts

# Generate a Go SDK with custom module name
specforge generate openapi.yaml -o ./sdk-go -l go -n github.com/acme/widget-go

# Generate a Rust crate
specforge generate openapi.yaml -o ./sdk-rs -l rust -n widget_sdk

# Lint with strict mode
specforge check openapi.yaml --strict

# Detect breaking changes between spec versions
specforge diff v1.yaml v2.yaml

Installation

Get specforge running on your machine in under a minute.

Cargo (from source)

Build from source with Rust
git clone https://github.com/amafjarkasi/specforge-openapi-sdk-codegen.git
cd specforge-openapi-sdk-codegen
cargo install --path crates/specforge-cli

Prebuilt Binary

Download for your platform
# Linux (x86_64)
curl -sSL https://github.com/amafjarkasi/specforge-openapi-sdk-codegen/releases/latest/download/specforge-linux-amd64 -o specforge
chmod +x specforge
sudo mv specforge /usr/local/bin/

GitHub Action

CI/CD integration
# .github/workflows/sdk.yml
- uses: amafjarkasi/specforge-openapi-sdk-codegen@v1
with:
spec: openapi.yaml
lang: ts
out: ./sdk

Verify Installation

Check that everything works
specforge --version
