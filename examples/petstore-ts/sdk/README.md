# Swagger Petstore SDK

Generated TypeScript SDK for **Swagger Petstore** (`@examples/petstore`). Targets `http://petstore.swagger.io/v1`.

## Install

```bash
npm install @examples/petstore
```

## Quick start

```ts
import { createClient, bearerAuth } from "@examples/petstore";

const client = createClient({ baseUrl: "http://petstore.swagger.io/v1", auth: bearerAuth(() => process.env.API_TOKEN!) });

// Each tag is a namespaced group of operations.
const result = await client.pets.listPets();
```

## Errors

All non-2xx responses (and network/timeout failures) throw a typed `ApiError`.
Narrow on `.type`:

```ts
import { isApiError } from "@examples/petstore";
try {
  await client.pets.listPets();
} catch (e) {
  if (isApiError(e)) {
    if (e.type === "http") console.error(e.status, e.body);
  }
}
```

## Pagination

```ts
import { cursorPaginator } from "@examples/petstore";
```

## Dedupe

Coalesce identical in-flight safe (GET/HEAD/OPTIONS) requests so concurrent callers share one round-trip:

```ts
const client = createClient({
  baseUrl: "http://petstore.swagger.io/v1",
  auth: bearerAuth(() => process.env.API_TOKEN!),
  dedupe: true,
});
```

## Middleware

Add request/response middleware using `client.use`:

```ts
client.use(async (req, next) => {
  console.log(`${req.method} ${req.url}`);
  const res = await next(req);
  console.log(`-> ${res.status}`);
  return res;
});
```

## Streaming / SSE

Consume server-sent events with `streamSse`:

```ts
const res = await client.pets.streamEvents();
for await (const event of streamSse(res)) {
```

## Interceptors

Transform the request body before it is serialized, or the response body after it
is deserialized, by implementing an interface and registering it on the client:

```ts
import { createClient } from "./index";

const client = createClient({
  baseUrl: "http://petstore.swagger.io/v1",
  requestInterceptors: [{
    transform(body) {
      // Add a trace_id to every outgoing request.
      return { ...body as object, trace_id: "abc-123" };
    }
  }],
});
```

## oneOf type guards

For `oneOf`/`anyOf` compositions, the emitter generates union-scoped runtime
type guards so you can safely narrow union types at runtime:

```ts
import { isPetEventPetCreated, narrowPetEvent, type PetEvent } from "./models/PetEvent";

function handle(event: PetEvent) {
  if (isPetEventPetCreated(event)) {
    console.log(event.pet.name); // narrowed
    return;
  }
  switch (narrowPetEvent(event)) {
    case "PetUpdated": /* … */ break;
    case "PetDeleted": /* … */ break;
  }
}
```

Guard names are union-scoped (`isPetEventPetCreated`, not `isPetCreated`) so two
unions sharing an arm type don't collide. `narrow{Union}()` is the ergonomic
entry point for most use cases.
